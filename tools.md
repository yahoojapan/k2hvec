# Tools
**K2HVEC** includes the following tools to support library operation and management:

- **[k2hveclinetool](tools_k2hveclinetool.html)**  
A command-line tool(interactive / command execution) for intuitively operating, testing, and performing vector searches on the database from an external interface.
- **[k2hvecpmtool](tools_k2hvecpmtool.html)**  
A dedicated tool for generating, updating, and loading the Projection Matrix used internally during data storage and similarity search processing.

**Note:** Bundled tools will continue to be updated and expanded with new features.
