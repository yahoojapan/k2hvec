**K2HVEC** - A high-performance **Vector** database for fast vector search, built on **K2HASH**.

### Overview
**K2HVEC** is a high-performance, KVS-based vector database built on top of the [K2HASH](https://github.com/yahoojapan/k2hash) Key-Value Store library.  
It uses vector embeddings(floating-point arrays generated by AI or machine learning models) as keys to store arbitrary data, delivering high-speed and accurate vector similarity searches.

![K2HVEC](https://k2hvec.antpick.ax/images/top_k2hvec.png)

### Key Feature
- **Arbitrary Data Storage**  
  Stores arbitrary user data(values) associated with corresponding vector embeddings used as keys.
- **Fast Vector Search**  
  Performs high-speed and accurate vector similarity searches using specified vector embeddings.
- **Full K2HASH Feature Inheritance**  
  Inherits all native K2HASH features, including data encryption, expiration limits(TTL), and custom attributes.
- **Interactive CLI Tool Provided**  
  Includes a dedicated interactive CLI tool for intuitive database management and operation.
