# **K2HVEC**
**K2HVEC** is a high-performance, KVS-based vector database built on top of the [K2HASH](https://github.com/yahoojapan/k2hash) Key-Value Store library.  
It uses vector embeddings(floating-point arrays generated by AI or machine learning models) as keys to store arbitrary data, delivering high-speed and accurate vector similarity searches.
**K2HVEC** is one of [AntPickax](https://antpick.ax/)'s open source product by LY Corporation.
